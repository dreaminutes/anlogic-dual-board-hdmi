双板连接与操作

一、板卡角色
两块板卡均为安路EG4S20BG256。
主板下载 bit/double_board_2_main_sw4_V10_TEST.bit，连接HDMI显示设备。
副板下载 bit/COMPAT_double_board_1_secondary_library_TEST.bit，插入TF卡。
主板负责缓存、显示、声音与交互，副板负责读取并提供媒体数据。

二、板间连接
采用工程原有直通IDC排线连接两板P4的19～44脚，共两排13列。
以蓝色VGA接口在左、拨码在上、P4排针在下为视角，左侧留9列，右侧留8列。
两端插头相对于各自板卡保持相同方向，红边对应19/20一端；不得错列或翻转。
两板共地并各自供电。断电后连接或拆卸排线，不连两板5V/3.3V输出。

主副板同球位相连的信号如下，完整定义见两工程pins.adc：
信号             球位       方向
link_data[0]     L16        副板 → 主板
link_data[1]     P14        副板 → 主板
link_data[2]     M14        副板 → 主板
link_data[3]     M13        副板 → 主板
link_data[4]     L13        副板 → 主板
link_data[5]     K11        副板 → 主板
link_data[6]     L14        副板 → 主板
link_data[7]     J12        副板 → 主板
forward_clk      K12        副板 → 主板
link_valid       J13        副板 → 主板
credit           J16        主板 → 副板
command          J14        主板 → 副板
其余排线信号按约束保持保留用途，P4的43/44为GND。

三、下载和启动
在BitWriter中选择EG4S20BG256，分别加载主板和副板BIT。
临时下载使用PROGRAM_SRAM，下载速度5MHz；掉电后SRAM程序丢失。
固化到板载M25P16时使用PROGRAM_FLASH，容量16Mbits。
准备好FAT32 TF卡，将生成的素材文件复制到根目录，安全弹出后插入副板。
两板SW0先置DOWN，主板SW7和SW6置DOWN；启动时先主板SW0 UP，再副板SW0 UP。
底板外接接口使用HDMI与TF卡。HDMI同时传送图像和音频。

四、主要操作
KEY7：手动切换下一素材。
KEY6：开启或关闭自动轮播。
SW4：进入或退出独立青蓝色音乐可视化场景。
SW5：选择背景音乐或视频原声。
SW6：进入或退出小游戏。
SW7：打开或关闭菜单。
游戏KEY12：开始或暂停；KEY13：复位；KEY1/KEY0：左移/右移。
上电默认为手动切换，字幕和媒体频谱叠加默认关闭；用户可在菜单中开启。
静态图片信息栏显示原始输入尺寸；GIF和视频显示实际新帧呈现FPS。
